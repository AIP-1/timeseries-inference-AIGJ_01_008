# 합성 데이터 생성기

제공 키트가 없어서 과제 안내문의 규칙대로 직접 만든 생성기다. 실데이터가 3주 이상 쌓이기 전까지 과제 2~8의 학습·평가에 쓴다.

## 실행

```bash
cd sim
python3 generate.py --out data/synthetic --weeks 6 --seed 42
# InfluxDB synthetic 버킷에 다시 넣기 (실데이터 sensors 버킷과 분리)
python3 to_influx.py data/synthetic/sensors.csv \
  | docker exec -i influxdb influx write --bucket synthetic --precision s
```

같은 시드면 항상 같은 데이터가 나온다. 시각은 모두 KST(시간대 표기 없음)이고, InfluxDB에는 UTC로 들어간다.

## 구성

| 공간 | 부피 | 기록 주기 | 사용 패턴 | 일정 자료 |
|---|---|---|---|---|
| classroom_a 강의실 A | 270m³ | 1분 | 평일 9~18시 수업, 정원 30·평균 26명 | 수업 시간표 |
| classroom_b 강의실 B | 200m³ | 1분 | 같은 시간표, 평균 18명 | 수업 시간표 |
| meeting 회의실 | 60m³ | 2분 | 하루 2~5건 예약, 2~8명 | 회의 예약 |
| lounge 라운지 | 180m³ | 5분 | 쉬는 시간·점심에 몰림 | 혼잡 예상 시간대 |

- 물리 모델: CO₂는 1인 배출량과 환기량으로 계산한 물질 수지, 온도는 외기 열 교환, 인체 발열, 냉방(설정 24℃, 평일 08:30~19:00)으로 계산했다.
- 일정과 실제 사용을 일부러 어긋나게 했다. 휴강 4%, 결석, 지각과 연장, 회의 노쇼 15%, 예약 없는 사용, 쉬는 시간 창문 개방이 들어 있다.
- 불완전함
  - 공간 공통 게이트웨이 끊김 2~12분
  - 공간별 긴 끊김 1~6시간
  - 메시지 개별 유실
  - 깨진 값 약 0.1%: 0ppm, 65535ppm, -40℃, 60℃
  - 측정 잡음: CO₂ σ 8ppm, 온도 σ 0.06℃
- 고장: 마지막 1주(시험 기간)에 5종 17건을 심었다.
  - 튄 값 6건
  - 값 고정 3건
  - 영점 틀어짐 2건
  - 냉방 정지 3건
  - 환기 정지 3건

## 출력 (`data/synthetic`)

| 파일 | 내용 | 모델 입력으로 써도 되나 |
|---|---|---|
| `sensors.csv` | 센서가 보낸 값. 결측·깨진 값·고장이 들어 있다 | ✅ |
| `schedule.csv` | 일정: space, start, end, kind(class/booking/break/lunch), expected 인원 | ✅ 미래 값도 미리 알 수 있다 |
| `truth.csv.gz` | 1분 단위 정답: occupants, occupied, co2_true, temp_true, gap, fault | ❌ 평가에만 쓴다 |
| `faults.csv` | 고장 이벤트: space, type, start, end, sensor | ❌ 평가에만 쓴다 |
| `meta.json` | 시드, 기간, 학습·검증·시험 분할, 공간 설정 | |

## 분할 (6주 기준)

| 구간 | 기간 |
|---|---|
| 학습 | 08-31 ~ 09-27 (4주) |
| 검증 | 09-28 ~ 10-04 (1주) |
| 시험 | 10-05 ~ 10-11 (1주, 고장 포함) |

시험 기간은 학습과 모델 선택에 쓰지 않는다. 정규화 값은 학습 기간 데이터로만 계산한다.

## 확인한 값 (seed 42, 고장 구간 제외 참값 기준)

- 평일 수업 중 강의실 CO₂는 평균 약 1,000ppm, 최대 약 1,300ppm이다. 1,000ppm을 넘는 비율은 강의실 13~14%, 라운지 2%, 회의실 1.5%다.
- '30분 안에 1,000ppm 초과' 양성 비율은 공간별로 0.9~4.7%다.
