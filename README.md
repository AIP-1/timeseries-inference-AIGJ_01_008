# 시계열 데이터 추론 실습 결과 (AIGJ_01_008, team2-2)

교육장 CO₂·온도·습도 센서를 받아 60분 예측, 이상 탐지, 사용 여부·환기 경보를 매분 내보내는 서비스를 팀 Jetson에서 혼자 만들고 평가한 결과다. 팀이 보드를 같이 쓰지만 개별 과제라서, 수집기부터 서비스까지 내 계정(`team2-2`)에 따로 만들었다.

## 요약

과제 1~8의 확인 기준을 모두 넘었다. 과제 1·8은 실데이터, 과제 2~7은 고장 정답이 있는 합성 데이터로 판정했다. 실데이터 60분 CO₂ 예측만 시간표가 없어 현재값 유지보다 18% 좋아지는 데 그쳤다(기준 30%).

| 과제 | 핵심 결과 | 판정 | 보고서 |
|---|---|---|---|
| 1. 데이터 수집 체계 | 재접속 6초, 재부팅 후 약 44초 만에 재개, 24시간 커버율 95.2~100% | 통과 | [task1](report/task1.md) |
| 2. 데이터 이해와 기준선 | 정제 규칙 6가지, 가장 강한 기준선은 현재값 유지(60분 CO₂ 44.0ppm) | 통과 | [task2](report/task2.md) |
| 3. 60분 예측 | GRU 4시간 20.5ppm, 현재값 유지보다 53% 작음. 일정 정보를 넣으면 3.2ppm 감소 | 통과 | [task3](report/task3.md) |
| 4. 이상 탐지 | 결합 탐지 82%(17건 중 14건), 헛경보 하루 0.86회 | 통과 | [task4](report/task4.md) |
| 5. 상태 추정 | 사용 여부 F1 0.854, 환기 경보 재현율 94.1%, macro-F1 0.895 | 통과 | [task5](report/task5.md) |
| 6. 사전학습 모델 비교 | Chronos-Bolt base 27.8ppm. 주 모델로는 채택하지 않음 | 통과 | [task6](report/task6.md) |
| 7. 엣지 최적화 | 변환 차이 CO₂ 0.27ppm, 지금 규모에는 ONNX Runtime CPU가 가장 빠름 | 통과 | [task7](report/task7.md) |
| 8. 상시 추론 서비스 | 약 15시간 919주기 연속, 계산 실패 0회 | 통과 | [task8](report/task8.md) |

## 측정 조건

| 항목 | 값 |
|---|---|
| 보드 | Jetson Orin Nano 8GB, JetPack 7.2.1, 25W 모드, 클럭 고정 안 함 (팀원 작업과 같은 보드) |
| 합성 데이터 | 직접 만든 생성기 seed 42, 2026-08-31 ~ 10-11 (6주). 학습 4주 · 검증 1주 · 시험 10-05 ~ 10-11 (고장 17건) |
| 실데이터 | 공용 InfluxDB `iot-bucket`에서 복사한 2025-08 ~ 2026-10-20 + 10-20부터 직접 수집. 시험 10-06 ~ 10-20. 시간표·고장 정답 없음 |
| 평가 | 기준선과 모든 모델을 같은 평가 지점에서 비교. 시험 기간은 학습·모델 선택에 쓰지 않음 |

## 서비스 접속

서비스는 팀 Jetson에서 돌고 있고, 교육장 Wi-Fi 안에서만 닿는다.

```bash
curl http://172.27.91.139:8090/health
```

```bash
curl 'http://172.27.91.139:8090/spaces/meeting/co2?minutes=30'
```

```bash
mosquitto_sub -h 172.27.91.139 -p 1884 -t 'team2-2/inference/#' -v
```

주소가 바뀌었을 때의 확인 방법은 [결과 형식 문서](docs/결과_형식_문서.md)에 있다.

## 폴더 구성

| 폴더 | 내용 |
|---|---|
| `report/` | 과제별 보고서 |
| `docs/` | 결과 형식 문서, 실행 방법, PDF |
| `collector/` | 과제 1 수집기(Docker), 설정 파일, 수집 현황 보고서 코드 |
| `sim/` | 합성 데이터 생성기 |
| `history/` | 공용 InfluxDB의 과거 데이터를 복사하는 스크립트 |
| `src/` | 과제 2~8 코드. `b*.py`는 심화 실험, `service.py`는 상시 서비스 |
| `models/` | 학습한 모델(PyTorch, ONNX, 분류기) |
| `results/synthetic/` | 합성 데이터 결과표와 그래프 |
| `results/real/` | 실데이터 결과표 |
| `results/collector/` | 수집 현황 자동 보고서(첫날, 제출일) |
| `results/service/` | 약 15시간 연속 가동의 주기별 기록 |

센서 원본 데이터와 비밀값(`.env`)은 저장소에 넣지 않았다. 필요한 설정 이름은 `.env.example`, `collector/.env.example`, `history/src.env.example`에 있다.
